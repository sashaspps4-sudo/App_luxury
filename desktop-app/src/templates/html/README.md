# HTML-шаблоны площадок

Для каждой площадки и доступного гео создан файл `template.html`. Заменяйте его содержимое своей готовой вёрсткой. Для Etsy используется единый шаблон `etsy/All/template.html`.

Примеры:

- `depop/AU/template.html`
- `kleinanzeigen/DE/template.html`
- `fiverr/ALL/template.html`

Коды стран совпадают с гео в настройках приложения. Предпросмотр HTML читает выбранный файл площадки и гео. `Custom` использует отдельный редактор и не зависит от кода страны.
